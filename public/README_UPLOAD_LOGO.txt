You can upload your official logo image directly to this folder (the 'public' folder) in any of the following formats:

1. PNG format (Recommended with transparent background):
   Name the file exactly: logo.png
   
2. SVG format:
   Name the file exactly: logo.svg
   
3. JPEG format:
   Name the file exactly: logo.jpg or logo.jpeg

Once uploaded, the system will automatically detect it and replace the beautiful fallback SVG drawings across the whole app (the Login Page, the Sidebar Navigation, the Headers, etc.) with your uploaded official logo perfectly.
